# D19 Fuse.js — 工程手册

## 适用

小到中等的客户端模糊查找。权限过滤必须发生在建索引之前。海量或需要中文分词的检索不要靠这次演示下结论。

## 版本

`fuse.js@7.5.0`。不要把未发布的扩展查询语法抄进这版。

## 迁移

带走 `examples/example.tsx`、`search-scope.mjs`、`index-lifecycle.mjs`。索引在数据或阈值变化时重建。查询只调用 `search`。

## 不可删的清理

分组先过滤再索引。同 id 更新用新数组重建，让旧词失效。组合输入期间不要提交查询。卸载后不要保留对旧 Fuse 的引用。

## 反例

- 每次按键 `new Fuse`。
- 用结果下标当 id。
- 先 `limit` 再按来源过滤。
- 把 score 写成跨版本阈值。
- `innerHTML` 高亮。
- 改原对象却不重建索引。
- 把 UI 分组当成 ACL。

## 测试断言

- 范围外的文档不会被搜到。
- 同 id 替换后旧标题不再命中。
- 空查询返回当前范围，而不是零条。
- 策略单测不是 Fuse SDK 通过。

## 真实限制

没有 Worker，没有序列化索引。中文分词没有在这个示例里配置。

## 证据

没有收据不要写 PASS。
