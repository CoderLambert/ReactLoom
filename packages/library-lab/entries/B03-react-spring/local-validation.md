## 实现与所有权

basic保留useSpring的opacity/translateY与240/28物理参数，按钮目标文字/aria-pressed即时变化；实际animated DOM抵达1/0px或0.45/18px，允许目标中断。不是内容折叠、无固定动画时长承诺。

business保留useTransition稳定item.id与from/enter/leave。业务数组更新即撤销操作，离场视觉行以当前数组membership决定data-active、aria-hidden、inert并移除按钮；transition.phase从SDK第三参取，仅作观察，不作为权限/存在判断。逻辑数量/ID输出与SDK DOM分开。恢复默认不回退nextId，避免复用新增身份；上限12和原生disabled保留。

advanced新增“仅本例减少动画”opt-in，effective=systemReduced||localReduced，不允许关闭系统已启用的偏好。两个SDK hook都接收immediate。没有Globals.assign；官方useReducedMotion会写全局skipAnimation，当前独立组件保留局部matchMedia change监听，卸载只移除自己的监听。SDK hook cleanup在匹配源码中停止各自Controller；未来自建命令式Controller需自行stop，不处理其它实例。

焦点策略保留：删除按钮实际持焦时记录目的地，layout effect在提交后消费一次待处理ref，等添加按钮从满员disabled变可用，再focus。未持焦不抢焦点，仍满员则兜底reset。effect每次提交检查pending ref（空则立即返回），不依赖动画结束，也不通过pointerdown或强制点击绕过正常交互。
